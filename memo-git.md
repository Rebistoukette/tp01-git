# Memo Git


### `git init`

Il permet de créé le dossier caché dans lequel il aura les sauvegarde et toutes les choses qu'il ne faut pas touché mais qui sont indispensable.

### `git status`

Il permet de voir quels fichiers sont dans le répèrtoire de travail, dans la zone de préparation ou de dépôt.

### `git add`

Il permet d'ajouter un fichier dans la zone de préparation.

### `git commit -m "..."`

Il permet d'envoyer les fichiers de la zone de préparation à la zone de dépôt.

### `git log --oneline`

Permet de voir tout les commit effectué en une seule ligne
